# Bienvenidos RN

Sitio web con información y guías para familias de recién nacidos, creado por Diego Steinberg, médico pediatra y neonatólogo con más de 25 años de experiencia.

🔗 **Sitio en vivo:** https://diegoastein.github.io/bienvenidosrn/

## Descripción

Bienvenidos RN es un sitio estático que reúne guías prácticas para acompañar a las familias en los primeros meses de vida de sus bebés, con el respaldo de un profesional especializado en el cuidado de recién nacidos y niños pequeños.

## Secciones

| Página | Descripción |
|---|---|
| **Inicio** | Presentación, guías destacadas y galería de imágenes |
| **Guías** | Material sobre el cuidado del recién nacido |
| **Preguntas frecuentes** | Respuestas a las dudas más comunes |
| **Contacto** | Datos para comunicarse |
| **Sobre mí** | Presentación del autor |

### Guías disponibles

- Cómo volver a casa
- Cómo cuidar a tu bebé
- Cómo alimentar a tu bebé
- Cómo cuidar el sueño de tu bebé
- Cómo cuidar la piel de tu bebé
